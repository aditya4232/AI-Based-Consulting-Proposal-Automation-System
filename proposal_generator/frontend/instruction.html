How to Use ProposeAI

Complete setup and usage instructions

Welcome to ProposeAI

ProposeAI combines Generative AI (for writing summaries and approaches) with Deterministic Logic (for strict math regarding costs, timelines, and team compositions) to create robust, hallucination-free project proposals.

By default, this system connects to a local Ollama instance for maximum privacy and zero cost. You can also securely use external APIs (Groq, OpenAI) for faster/larger models.

Setting Up Ollama (Primary / Default)

Ollama allows you to run large language models locally on your machine. We highly recommend this to prevent sending proprietary client data to external providers.

1
Install Ollama
Download and install Ollama from ollama.com.
2
Download a Model
Open your terminal or command prompt and run:
ollama run llama3 or ollama run mistral
Wait for the download to finish. It will start the server automatically on http://localhost:11434.
3
Keep it running
As long as the Ollama app/service is running, this web application will automatically detect the active model and connect to it. No API keys are needed!

Using External APIs (Optional)

If you prefer to use cloud providers like Groq or OpenAI for faster generation or specific models, you can easily configure them directly in the UI.

  • Safe Configuration: API keys entered in the UI are kept purely in your browser's local storage and sent directly to the backend ONLY when generating a proposal. They are never logged or stored on the server.
  • How to apply: Go to the Settings tab in the sidebar layout. Select Groq or OpenAI, enter your API Key, and save.

Features & Workflows

1. The "Magic Generate" Bar

At the top of the dashboard, you can type a natural language prompt like "Generate a proposal for Acme Inc.'s cloud migration in AWS taking 6 months for 5000 users". The AI will parse this and pre-fill the form for you.

2. PDF & Draft Generation

  • Preview Draft (JSON): Returns the raw structured data so you can verify the LLM output without generating a document.
  • Generate PDF: Generates the intelligent text, calculates deterministic costs (no hallucinations!), forms the team structure, builds charts using matplotlib, and creates a polished PDF download.

3. Cost Logic Architecture

Cost and timelines are calculated via strict math formulas in app/cost_logic.py based on the `duration_months` and `expected_users` variables. The LLM is instructed explicitly to not hallucinate financial numbers. The backend intercepts the LLM's timeline and forces its weeks to strictly sum to your requested duration.
